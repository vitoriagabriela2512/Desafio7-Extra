📖 Descrição

Este projeto reúne uma série de 6 exercícios práticos em PHP, com foco em Programação Orientada a Objetos (POO), lógica de programação e integração com formulários HTML.

Cada exercício simula uma situação do mundo real, aplicando conceitos como:

Classes e objetos
Métodos e atributos
Cálculos automatizados
Entrada de dados via formulário
Exibição de resultados dinâmicos
🎯 Objetivo

Desenvolver habilidades em:

PHP orientado a objetos
Estruturação de projetos
Lógica de programação
Organização de código
Integração entre front-end e back-end

💻 Como Executar o Projeto
Instale um servidor local (XAMPP recomendado)

Coloque a pasta do projeto em:

C:\xampp\htdocs
Inicie o Apache no XAMPP
Acesse no navegador:
http://localhost/Desafio7Extra
